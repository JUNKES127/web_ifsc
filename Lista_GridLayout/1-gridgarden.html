Atividade 1 - CSS Grid Garden

Jogo jogado: Grid Garden. Cada nível pede para posicionar a água (e depois o veneno) em cima das cenouras certas usando propriedades de CSS Grid aplicadas ao contêiner (a horta) ou aos itens individuais.

Joguei os 28 níveis do jogo. Abaixo está a explicação de um dos níveis.

Explicação detalhada de 1 nível

Nível 7 - grid-column-end: span 2;

Nesse nível a água já começa na segunda coluna (grid-column-start: 2;) e precisa cobrir duas colunas para regar as cenouras. Em vez de calcular em qual linha do grid ela termina, usei span: grid-column-end: span 2; quer dizer "atravesse 2 colunas a partir do início". É importante lembrar que os números do grid são linhas de grade (as divisões entre as colunas, contadas a partir de 1), e não as colunas em si. Então o mesmo resultado também daria com grid-column-end: 4;, que é a linha onde a segunda coluna termina. O span é mais prático quando o que importa é quantas colunas ocupar.
